# Mojimaro AI Clipper

A mobile-friendly starter interface for an AI video clipping platform.

## Current status
This is the **front-end starter**, not a working AI clipping engine yet. It includes:
- Responsive dashboard UI
- Video URL input and local file picker
- Clip-style and clip-count selectors
- Browser-only project preview list

It does **not** yet download videos, upload files to a server, analyse footage, generate subtitles, render MP4 clips, authenticate users, or store projects in a cloud database.

## Run locally
Open `index.html` in a browser, or publish this repository with GitHub Pages.

## Publish with GitHub Pages
1. Push these files to the root of your GitHub repository.
2. Open repository **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Content rights
Only process videos you own or have permission to use. A public video URL does not automatically grant permission to download, edit, or repost it.

## Security
Never put API keys, service-account files, or private credentials in this public repository or browser JavaScript. Keep secrets on a secure server.
